# IGI Insurance Automation System

Complete backend-driven insurance automation system for IGI Insurance.

## Quick Start

```bash
docker-compose up --build
```

- Frontend: http://localhost:3000
- Backend API: http://localhost:8000
- API Docs: http://localhost:8000/docs

## Features

- Complete policy management with 15+ modules
- Automated premium calculations
- CSV-based payment reminders (daily at 8 AM)
- Gmail integration for auto-policy creation
- PDF document generation
- Real-time validations

## Tech Stack

- Backend: Python, FastAPI, SQLAlchemy, PostgreSQL
- Frontend: React, TypeScript, Vite
- Automation: APScheduler, Gmail API
- Documents: Jinja2, WeasyPrint
